星载中继通道冗余配对复核

切除故障通道后，按无向兼容关系为剩余设备寻找覆盖全部通道的两两配对。 计算在 Web Worker 中按一般图（非二分图）语义执行 Edmonds 缩花算法； 无法配对时给出可凭原图逐项核对的 Tutte 失败证书。 还可把某条已录入的兼容边指定为必须共同接管的固定组合做预演： 仅在删去其两个端点后的剩余图上复核，确认这一人为绑定不会让其余通道失去安置机会。

固定配对预演（可选）

将某条已录入的兼容边指定为必须共同接管的固定组合： 仅在删去其两个端点后的剩余图上复核完整配对，确认这一人为绑定不会让其余通道失去安置机会。

—

校验规则

  • 通道须为 3–48 个唯一标识，且总数为偶数；
  • 拒绝自环、重复边、含未知端点的边；
  • 拒绝空边图（没有任何兼容边时偶数个孤立通道无法配对）；
  • 成功：配对覆盖全部通道，每对均为录入边，按通道标识升序稳定展示；
  • 失败：展示移除集合 S 与 S 删除后的每个奇数连通分量，奇数分量数严格大于 |S|，并可对照原图逐项核对；
  • 固定配对预演：指定一条已录入且端点不同的兼容边为固定组合，仅在删去其两个端点的剩余图上求完整配对；可行时固定组合与剩余配对合并展示，全部通道各出现且仅出现一次；不可行时证书仅针对剩余通道，不能误作原图的失败证书；
  • 任何失败提交都会清空上一次通过的配对，不保留旧结果。
