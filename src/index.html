星载中继通道冗余配对复核

切除故障通道后，按无向兼容关系为剩余设备寻找覆盖全部通道的两两配对。 计算在 Web Worker 中按一般图（非二分图）语义执行 Edmonds 缩花算法； 无法配对时给出可凭原图逐项核对的 Tutte 失败证书。

固定配对预演

在已取得完整配对的基础上，指定一条已录入的兼容边为必须共同接管的固定组合： 系统删去这两个通道后，仅在剩余图上继续按一般图求完整配对。 剩余图若不可配对，给出的阻塞集合只针对剩余通道，不作为原图的失败证书。

校验规则

  • 通道须为 3–48 个唯一标识，且总数为偶数；
  • 拒绝自环、重复边、含未知端点的边；
  • 拒绝空边图（没有任何兼容边时偶数个孤立通道无法配对）；
  • 成功：配对覆盖全部通道，每对均为录入边，按通道标识升序稳定展示；
  • 失败：展示移除集合 S 与 S 删除后的每个奇数连通分量，奇数分量数严格大于 |S|，并可对照原图逐项核对；
  • 任何失败提交都会清空上一次通过的配对，不保留旧结果。

固定配对预演规则

  • 固定组合只能由两个已录入的不同通道发起，且它们之间必须存在已录入的兼容边；
  • 校验通过后删去固定两端，仅在剩余图上求完整配对，计算仍走一般图 Edmonds 缩花；
  • 可行：固定组合与剩余配对合并后按标识升序展示，所有通道只出现一次；
  • 不可行：展示的 Tutte 阻塞集合与奇数分量仅针对剩余通道，不能当作原图的失败证书；
  • 边不存在、通道未知/相同或本次输入校验失败时给出明确反馈并清除旧的固定结论；一般「复核配对」语义不变、独立工作。
